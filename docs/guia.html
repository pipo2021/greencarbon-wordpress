01Qué se entrega

El sitio de una sola página de Green Carbon Bolivia, con el recorrido en video que avanza con el scroll, convertido en un tema de WordPress. Todo el contenido (textos en español e inglés, fotos, enlaces, datos de contacto y avisos pendientes) se edita desde un único administrador, con vista previa en vivo. Viene empaquetado en un contenedor Docker que instala todo solo.

Archivo / carpetaPara qué sirve
LEEME.mdResumen técnico (este PDF lo amplía).
docker-compose.yml, DockerfileDefinen los dos contenedores: WordPress (con el tema adentro) y la base de datos.
.env.ejemploPlantilla de configuración: contraseñas, usuario admin, URL y puerto. Se copia a .env.
docker/Script de arranque e instalación automática (instalar.sh).
tema/greencarbon/El tema de WordPress listo para usar (≈ 250 MB por el video y los cuadros).
herramientas/Generador del tema (convertir.py), traducción al inglés (traduccion-en.json) y scripts del video.
greencarbon-wordpress-1.2.2-amd64.tar.gzImagen Docker ya construida para servidores x86 (adjunta al Release, no está en el repo).
¿No usan Git? No hace falta. En la página del Release (github.com/pipo2021/greencarbon-wordpress/releases) se descarga «Source code (zip)» y la imagen desde el navegador. El repositorio es público: no hace falta cuenta de GitHub ni invitación.

02Instalación rápida con Docker

Pensado para alguien con conocimientos básicos. Se hace una sola vez; tarda unos 5 minutos más la descarga.

Requisitos

  • Docker Desktop (Windows / macOS) o Docker Engine + Compose v2 (Linux). Se descarga de docker.com.
  • 2 GB de RAM libres y 3 GB de disco.
  • Internet en la primera instalación (descarga WordPress en español). Sin internet funciona igual, con el admin en inglés.

Pasos

1

Descargar y descomprimir el «Source code (zip)» del Release v1.2.2. Queda una carpeta greencarbon-wordpress-1.2.2. Abrir una terminal dentro de esa carpeta.

2

Crear el archivo de configuración copiando la plantilla:

cp .env.ejemplo .env        # en Windows (PowerShell): copy .env.ejemplo .env
3

Editar .env con cualquier editor de texto y cambiar como mínimo las dos contraseñas:

VariableQué poner
DB_PASSWORDContraseña de la base de datos. Larga y aleatoria; nadie la escribe a mano.
GC_ADMIN_USERUsuario del administrador. Por defecto admin-greencarbon.
GC_ADMIN_PASSWORDContraseña del administrador (mínimo 12 caracteres).
GC_ADMIN_EMAILCorreo del administrador (para recuperar la contraseña).
GC_URLDirección del sitio. En local: http://localhost:8080. En producción: https://dominio.
GC_PUERTOPuerto de la máquina donde se publica (por defecto 8080). Debe coincidir con el de GC_URL en local.
GC_INDEXAR0 = los buscadores no indexan (pruebas). 1 = producción.
4

Levantar los contenedores (la primera vez construye la imagen, 1–3 minutos):

docker compose up -d --build
5

Esperar el mensaje «Listo». El servidor web arranca recién cuando terminó la instalación:

docker compose logs -f wordpress      # salir con Ctrl+C
[gc-instalar] Listo: http://localhost:8080/wp-admin (usuario admin-greencarbon).
6

Abrir el sitio en http://localhost:8080 y el administrador en http://localhost:8080/wp-admin.

Alternativa: usar la imagen ya construida (servidores x86)

Evita el paso de construcción. Descargar greencarbon-wordpress-1.2.2-amd64.tar.gz del Release y ponerlo en la misma carpeta:

docker load -i greencarbon-wordpress-1.2.2-amd64.tar.gz
docker tag greencarbon-wordpress:1.2.2-amd64 greencarbon-wordpress:1.2.2
docker compose up -d --no-build
En Mac con Apple Silicon usar el paso 4 (construye la imagen nativa). La imagen amd64 también funciona ahí, pero emulada y más lenta.

Comandos de todos los días

ComandoQué hace
docker compose psVer si están corriendo.
docker compose stop / startDetener / volver a arrancar sin perder nada.
docker compose logs -f wordpressVer el registro del servidor.
docker compose up -d --buildAplicar una versión nueva del tema (no borra contenido).
docker compose downApagar y quitar contenedores (el contenido queda en los volúmenes).
docker compose down -vBorra todo, incluido el contenido cargado. Solo para empezar de cero.

03Acceso al administrador y credenciales

DatoValor
DirecciónGC_URL + /wp-admin
(local: http://localhost:8080/wp-admin)
UsuarioEl de GC_ADMIN_USER en .env. Por defecto admin-greencarbon.
ContraseñaLa de GC_ADMIN_PASSWORD en .env.
RolAdministrador (único usuario).
Las credenciales no viajan en la entrega. El repositorio y el zip traen solo .env.ejemplo, con valores cambiar-esto. Cada instalación define sus propias contraseñas en .env, y ese archivo nunca se sube a Git. La instalación de prueba de Álvaro tiene las suyas en su .env local: si se necesitan, pedirlas por un canal privado, nunca por correo abierto.

Las credenciales del .env se usan solo en la primera instalación. Después, cambiar la contraseña en el .env no cambia la del sitio. Para cambiarla:

  • Desde el admin: Usuarios → Perfil → Nueva contraseña.
  • Desde la terminal, si se olvidó:
docker compose exec wordpress wp --allow-root user update admin-greencarbon --user_pass='NuevaClaveSegura'

Al entrar, el contenido está en Apariencia → Personalizar → Contenido de la web. También se llega desde el escritorio del admin.

04Qué se puede modificar

El panel Contenido de la web tiene 21 secciones en el mismo orden que la página y 354 campos. Cada cambio se ve al instante en la vista previa, pero no se publica hasta pulsar «Publicar», arriba a la izquierda. También se puede guardar como borrador o programar.

Tipo de contenidoCómo se edita
Textos (títulos, párrafos, botones, menú, pie, formulario)Campo de texto. Se permiten <em>, <strong>, <b>, <br> y <a href>; el resto se elimina por seguridad. Los títulos con una parte en verde están divididos en dos campos («Título» y «Resaltado»).
InglésCampo «EN ·» debajo de cada texto. Si se deja vacío, en inglés se muestra el español. La versión en inglés se ve en ?lang=en o con el botón ES | EN de la cabecera.
FotosBotón «Cambiar imagen»: se sube a la Biblioteca de medios o se elige una existente. Cada foto tiene además su texto alternativo (ES/EN) para accesibilidad.
Retratos y foto de especieHuecos de imagen. Vacíos muestran la silueta o el aviso «Falta».
Avisos «Falta» / «SSOT»Cada aviso naranja o amarillo tiene su campo. Al escribir el dato real, el aviso desaparece y se muestra el dato. Vacío = vuelve el aviso.
Enlaces externosRedes sociales, Verra, destino del formulario: campo URL.
Mapa del proyectoImagen estática (a pedido del cliente): sección 6 → «Imagen estática del mapa del proyecto». Se exporta el mapa de las TCO desde Global Nature Watch (horizontal, mínimo 1600 px de ancho) y se sube aquí. Lleva el crédito «Fuente: Global Nature Watch». Vacía = aviso «Falta imagen del mapa».
Centro de Operaciones de IncendiosImagen estática (a pedido del cliente), sin enlace a claude.ai, con la leyenda «Imagen ilustrativa». La imagen se cambia en la sección 10.
GeneralTítulo de la pestaña y descripción para buscadores (ES/EN), selector de idioma, opacidades y dos enlaces opcionales para más adelante: mapas y monitoreo de incendios. Si se completan, reemplazan la imagen estática por la página en un iframe; el sitio enlazado tiene que permitir ser embebido en el dominio.
Opacidad de hojas y tarjetasTres deslizadores (hojas claras, hojas verdes, tarjetas): 1 tapa el video; más bajo deja ver el recorrido detrás.
Mensajes de la páginaTextos que escribe el JavaScript: MENÚ/CERRAR, «Cargando el territorio», mensajes del formulario (ES/EN).
«Del bosque a los datos»Casilla en la sección 9 para mostrarla (oculta hasta la certificación, aprox. marzo 2027). Ver sección 11: al activarla, desarrollo tiene que ajustar las anclas del video.

05Qué NO se modifica desde el panel

ElementoPor qué / cómo se cambia
El recorrido en videoComputadora: video/recorrido-1080p60.mp4 (1080p, 60 fps, 75 MB). Celular: cuadros WebP en pack/v (540×960, 48 fps, 102 MB en 8 paquetes de grueso a fino). Respaldo: pack/h (24 fps). Se generan con los scripts de herramientas/video/. Si se reemplazan, hay que subir VERSION en js/main.js: los archivos se llaman igual y el navegador los guarda en caché.
Anclas data-cuadroAtan cada sección a un cuadro del video. Están en el HTML fuente.
Diseño, íconos y orden de seccionesstyle.css e index.php, generados desde el HTML original.
Cantidad de elementosHay 5 testimonios, 4 cifras de impacto, 1 especie y 5 piezas en «Comunidades en acción». Para agregar o quitar elementos hay que tocar el HTML fuente y regenerar.
No se usan plugins: son menos puntos de falla y menos actualizaciones. El editor de archivos del admin está desactivado (DISALLOW_FILE_EDIT) y la barra de administración se oculta en el frente, porque tapa la cabecera fija.

06Cómo está hecho el tema

El sitio original es un único index.html (HTML + CSS + JS). En vez de reescribirlo a mano, un generador lo convierte en tema. Así el diseño queda idéntico, y cualquier cambio de diseño se sigue haciendo en un solo archivo.

index.htmlSitio estático original (greencarbon-web)
→
convertir.pyCada texto, imagen, enlace y aviso pasa a ser un campo con su valor actual como predeterminado
→
tema/greencarbonindex.php · style.css · js/main.js · inc/campos.json · functions.php
→
Imagen DockerWordPress + tema + instalación automática
Archivo del temaQué contiene
index.phpLa página entera. Cada texto es una llamada como gc_t("s01_02"). Generado: no editar a mano.
inc/campos.jsonDefinición de los 354 campos: sección, tipo, etiqueta, valor predeterminado (ES) y traducción (EN).
functions.phpRegistra el Personalizador a partir de campos.json, funciones de salida con escape (gc_t, gc_a, gc_u, gc_aviso…), idioma, opacidades y carga de CSS/JS.
style.css / js/main.jsCSS y JS del original. El JS recibe window.GC con la ruta del tema, los enlaces y los textos traducidos.
assets/, video/, pack/Fotos, íconos, MP4 y paquetes de cuadros.

Idiomas

Español por defecto; inglés con ?lang=en. Cada campo de texto clave tiene un gemelo clave_en. gc_valor() elige según el idioma y, si el inglés está vacío, usa el español. La página emite <html lang> correcto y <link rel="alternate" hreflang>.

Video y scroll

En computadora el scroll mueve currentTime del MP4: se descarga entero a un blob local para que los saltos sean instantáneos (mediana medida: 6,6 ms por salto). En celular se dibujan cuadros WebP en un canvas, con fundido entre cuadros vecinos. Las anclas están en cuadros de 24 por segundo. El manifest.json de cada paquete declara sus fps y el JS hace la conversión. Los 60 y 48 fps se obtuvieron interpolando (ffmpeg minterpolate).

Regenerar el tema después de cambiar el HTML

python3 herramientas/convertir.py ../greencarbon-web tema/greencarbon
docker compose up -d --build
Las claves de los campos (s05_03…) son posicionales: agregar o quitar un texto en una sección corre las claves siguientes de esa sección, y el contenido ya cargado en esos campos queda desfasado. Después de un cambio de estructura hay que revisar esa sección en el panel. El generador verifica solo que, con los valores predeterminados, el texto visible sea idéntico al del HTML original.

07Instalar en un WordPress existente (sin Docker)

Si el hosting ya tiene WordPress (6.4 o superior, PHP 8.1 o superior):

  1. Subir la carpeta tema/greencarbon completa a wp-content/themes/ por SFTP o el administrador de archivos del hosting. Pesa unos 250 MB: el subidor de temas del admin no lo acepta por tamaño.
  2. En el admin: Apariencia → Temas → Green Carbon Bolivia → Activar.
  3. Subir el límite de subida de archivos a 64 MB (en php.ini o el panel del hosting) para poder cargar fotos grandes.
  4. En Ajustes → Lectura, la página de inicio puede quedar en «Tus últimas entradas»: el tema muestra la página única en cualquier caso.
  5. Recomendado: agregar define('DISALLOW_FILE_EDIT', true); en wp-config.php.
El servidor tiene que entregar .mp4 con Accept-Ranges (lo normal en Apache y Nginx) y no comprimir los .bin de pack/ al vuelo (ya están comprimidos).

08Pasar a producción

  1. Dominio y HTTPS: poner un proxy inverso (Nginx, Caddy, Traefik o el del hosting) con certificado delante del contenedor. Publicar el puerto solo en local cambiando en docker-compose.yml "${GC_PUERTO}:80" por "127.0.0.1:${GC_PUERTO}:80".
  2. GC_URL con https://dominio antes de la primera instalación. Si se instaló con otra URL: 
    docker compose exec wordpress wp --allow-root search-replace 'http://localhost:8080' 'https://dominio'
  3. GC_INDEXAR=1 cuando el cliente apruebe publicar, y docker compose up -d.
  4. Contraseñas fuertes y únicas en .env. Las variables se ven con docker inspect: en servidores compartidos conviene usar secretos del orquestador.
  5. Completar la lista de la sección 11.

09Mantenimiento: respaldos y actualizaciones

Hay dos volúmenes que respaldar: db (base de datos: todo el contenido del panel) y uploads (fotos subidas).

# Respaldo de la base
docker compose exec db sh -c 'mariadb-dump -u greencarbon -p"$MARIADB_PASSWORD" greencarbon' > respaldo-$(date +%F).sql

# Respaldo de las fotos subidas
docker compose cp wordpress:/var/www/html/wp-content/uploads ./uploads-$(date +%F)

# Restaurar la base
docker compose exec -T db sh -c 'mariadb -u greencarbon -p"$MARIADB_PASSWORD" greencarbon' < respaldo-AAAA-MM-DD.sql

Actualizar el tema

Con una versión nueva del repositorio: docker compose up -d --build. Al arrancar, el contenedor copia el tema nuevo y conserva el contenido.

Actualizar WordPress

Las actualizaciones menores de seguridad se aplican solas. Para una versión mayor, se puede actualizar desde el admin (queda en el volumen) o cambiar la versión en la primera línea del Dockerfile y reconstruir. Hay que hacer un respaldo antes.

10Solución de problemas

SíntomaSolución
«port is already allocated»El puerto está en uso: cambiar GC_PUERTO (y el puerto de GC_URL) en .env.
«falta GC_ADMIN_PASSWORD / GC_URL en .env»No se creó .env o falta esa línea (paso 2 y 3).
El sitio no abre después de upTodavía está instalando: docker compose logs -f wordpress hasta ver «Listo».
Redirige a otra direcciónGC_URL distinto del real: usar search-replace (sección 08).
Olvidé la contraseñaComando wp user update de la sección 03.
Cambié el video y se ve el viejoSubir VERSION en js/main.js (caché del navegador).
El video se ve a saltos en una pestaña de fondoNormal: el navegador frena las animaciones de pestañas que no se ven. Probar con la pestaña en primer plano.
